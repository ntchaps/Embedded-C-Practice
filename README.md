# Embedded C Practice

This repository is where I am working through small Embedded C exercises to build up my C fundamentals and get more comfortable with the kind of problems that come up in embedded systems.

I will be adding practice involving pointers, memory, bitwise operations, data structures, hardware-oriented logic, and anything else I need to spend more time with. Most of these exercises are meant to run locally without hardware, but I may add MCU-specific practice as I go.

Each folder contains the work for a practice day or topic. I am keeping this as a record of my progress, so some solutions may be revisited or cleaned up later.

## Building

For a standalone exercise, compile and run it with:

```bash
clang -Wall -Wextra exercise_name.c -o exercise_name
./exercise_name
